This is the introduction section of the template. It demonstrates how to
cite references with \texttt{natbib}: \texttt{\textbackslash citep} produces
a parenthetical citation, \citep{author2020example} for example, while
\texttt{\textbackslash citet} produces a textual citation, as in
\citet{author2018book}. Multiple sources can be grouped in one citation
\citep{author2019chapter,author2024working}. For a citation with a prefix or
a page range, use the optional arguments, e.g.,
\citep[e.g.,][]{author2020example} or \citep[pp.~12--14]{author2018book}.

A typical introduction closes by outlining the structure of the paper. The
following example uses cross-references; update the section labels to match
your own paper:

\begin{itemize}
  \item Section~\ref{sec:argument-part-1} presents the main argument.
  \item Section~\ref{sec:background} provides relevant background.
  \item Section~\ref{sec:sample} describes the research design.
  \item Section~\ref{sec:main-results} reports the results.
  \item Section~\ref{sec:conclusion} concludes.
\end{itemize}
